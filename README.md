# 🏏 Cricket Score React Docker

A Dockerized React cricket score application built for Docker and deployment practice.

---

## 🚀 Tech Stack

* ⚛️ React
* 📘 TypeScript
* ⚡ Vite
* 🐳 Docker

---

## 📦 Build Docker Image

```bash
docker build -t cricket-app .
```

---

## ▶️ Run Docker Container

```bash
docker run -d -p 8080:8080 cricket-app
```

---

## 🌐 Access Application

Open in browser:

```bash
http://localhost:8080
```

or

```bash
http://<EC2-PUBLIC-IP>:8080
```

---

## ✨ Features

* 🐳 Dockerized React application
* 🚀 Easy container deployment
* ☁️ AWS EC2 compatible
* ⚡ Fast Vite setup
* 📱 Responsive cricket score UI

---

## 🛠️ Deployment

This project was containerized and deployed using Docker on AWS EC2 for DevOps practice.
